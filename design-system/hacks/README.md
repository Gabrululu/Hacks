# Hacks design identity

`design.md` and `tokens.css` are generated from the root `tinte.config.json` with Tinte. Edit the config, then run `pnpm tinte:build` to regenerate both artifacts.

These files describe the fixed Hacks interface. Event organizers can set separate colors and typography for their own event landing pages; do not replace those per-event values with Hacks tokens.
